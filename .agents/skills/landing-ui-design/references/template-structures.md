# Template Structures

Treat these as purposeful starting journeys, not mandatory universal sequences.

## Product

Hero -> visual product proof -> quantified proof -> benefits -> offer/pricing -> social proof -> objections -> conversion.

## Service

Hero -> credibility -> selected work -> process/benefits -> social proof -> engagement options -> objections -> consultation.

## Course

Hero -> learner outcomes -> curriculum/benefits -> social proof -> enrollment options -> objections -> registration.

## Event

Hero with event facts -> credibility or speakers -> agenda/value -> registration -> practical questions -> final reminder.

## Portfolio

Hero -> selected work -> visual gallery -> testimonial -> credentials/process -> project inquiry.

## Lead Generation

Hero -> short form or offer capture -> proof -> deliverables/benefits -> testimonial -> objections -> final CTA.

When a planner recommends extra sections, preserve the purpose-specific base journey and add only sections that materially support the conversion goal.
